# Roadmap — Digital Industrial Workflow System (DIWS)

## Phase 1 — MVP Foundation
- Authentication
- Company onboarding
- RBAC
- Core master data
- Inventory and warehouse
- Procurement
- Production
- Sales and dispatch
- Dashboard and reports
- Document upload

## Phase 2 — AI + RAG
- Company knowledge base
- PDF/document parsing
- Embeddings and vector search
- AI chat interface
- Document Q&A
- AI summaries and report generation

## Phase 3 — Operational Expansion
- Machine management
- Quality module
- Maintenance module
- QR/barcode support
- Notifications and approvals
- Activity audit trail

## Phase 4 — Automation
- Background jobs
- Scheduled reports
- Smart alerts
- Recommendation engine
- Optional OCR

## Phase 5 — Advanced Platform
- Workflow builder
- Mobile app
- IoT integrations
- Third-party integrations
- AI agents
- Predictive analytics
