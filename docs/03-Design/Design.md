# Design — Digital Industrial Workflow System (DIWS)

## Design Goals
- Clean industrial look
- Easy-to-scan dashboards
- Strong visual hierarchy
- Fast admin-style navigation
- Mobile responsive layout

## Design Principles
- Keep actions visible
- Use cards for KPIs
- Use tables for operations
- Use filters for large data sets
- Keep forms simple and segmented
- Show status badges clearly

## Visual Style
- Neutral base colors
- One strong primary accent
- Subtle shadows
- Rounded cards
- Clear typography
- Minimal clutter

## UI Patterns
- Left sidebar navigation
- Top bar with company switcher and user menu
- Cards for summaries
- Tables for inventory/orders
- Drawer or modal for quick edits
- Timeline for activities

## AI Screen Direction
- Chat-style assistant
- Document source links
- Suggested prompts
- Answer with citations from documents
